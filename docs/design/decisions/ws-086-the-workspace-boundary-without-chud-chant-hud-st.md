    how: "This restates ws-052 with five owners. chant keeps everything ws-052 gave it and takes the plugin column's domain rows: the domain record kinds as the reference workspace's kinds, shipped as data and upgraded through lineage (#3148), the commit trailers that join a commit to its lease, run, records and apply (#3149, ws-075), the decision-point standards (#3150) and the factory's rules (#3162, ws-087). hud keeps rendering, review actions, the agent chat, the dev proxy, comment mode and the question at each finding, and identity and sessions as #3163 amended them. studio becomes an owner: orchestration and hosting (boxes, the lobby, the door, the planter and beds), how a builder runs, an agent's prompt and context bundle, and the push and pull request behind a publish (ws-088). Its rules: studio never defines a record field, never parses a record file and never holds a fact outside the repo (ws-074); it reads through the read contract and writes through the write contract, which its CI shows with the reader and writer conformance suites (#3159). behold becomes an owner as a reader: it reads only through the read contract and writes only through chant, under hud's rules. A plugin keeps the record kinds a workspace pins from a third party and their commitJoins, which the intent graph turns into unit, contract and evidence nodes and produced-by, serves and cites-evidence edges. chud is no longer an owner anywhere. The roster names the five owners, test/boundary-roster.test.ts holds studio's rows to arugula-salad/studio and behold's to INTENTIUS/behold, fails on a row that names chud as an owner, and keeps the plugin column to the pinned kinds and their joins."
    tradeoff: "Every concept has an owner who exists, and the orchestrator is held to the same read and write rules as the UI. chant carries the domain kinds a development model needs instead of leaving them to a package, so a new kind or field is a chant change. The chud-lexicon-exit migrations keep their names, since old boxes still need them."
  - id: "b"
    label: "amend ws-052 in place, swapping chud for chant in the plugin column"
    how: "Keep ws-052's three owners and change only the sentence that names chud as the plugin column's transitional owner, so the plugin column becomes chant's own kinds."
    tradeoff: "The smallest change: one sentence and a carrier per row. studio and behold stay off the roster, so nothing checks that the orchestrator reads and writes only through chant, and a decided record's text can't be changed by amend."
  - id: "c"

  - id: "d"

What stays outside chant is runtime and hosting, which is studio's, and the record kinds a workspace pins from someone else, whose joins still reach the intent graph through commitJoins. studio and behold read and write the repository as hud does, so naming them on the roster with the same read and write rules is what keeps the orchestrator an orchestrator and the infra plane a reader. A decided record keeps its text, so this record supersedes ws-052 and restates its rules rather than editing it, and every rule ws-052 made for chant and hud stands."
