Some lexicons provide an `import` command that converts existing infrastructure templates into chant TypeScript resource definitions. Import your current templates to adopt chant without rewriting them.

## General Workflow

```bash
chant import <template-file> --output src/
chant build
```

The import process:

1. Reads the existing template
2. Maps resources to lexicon types
3. Converts property names to TypeScript conventions
4. Generates TypeScript files organized by resource
5. Generates import statements for cross-resource references

See your lexicon's documentation for provider-specific import commands and options.

## Verifying Imports

Lexicons may provide roundtrip tests that verify the full import pipeline:

1. **Parse** the original template into an intermediate representation
2. **Generate** TypeScript source from the IR
3. **Import** the generated code (verifying constructors resolve)
4. **Serialize** back to the target format
5. **Compare** the output structurally against the original

The Kubernetes lexicon includes a full roundtrip suite and optional k3d cluster validation. See the [K8s Testing & Validation](/chant/lexicons/k8s/testing/) docs for details.

The OpenTelemetry Collector lexicon imports collector YAML and checks that every fixture builds back to the same config, with `otelcol validate` over the result when `otelcol-contrib` is installed. See [Importing a Collector Config](/chant/lexicons/otel/importing/).

Prometheus rule files and `alertmanager.yml` import the same way: every fixture must build back to the same file, and `promtool check rules` and `amtool check-config` run over the result when those are installed. [Importing Rule Files and alertmanager.yml](/chant/lexicons/prometheus/importing/) has the details.

The Grafana lexicon imports dashboard JSON exported from Grafana's UI and checks that Grafana 12.4 and 13.2 exports and community dashboards from grafana.com build back to the same dashboard, with anything it cannot carry printed as a warning. See [Importing Dashboards](/chant/lexicons/grafana/importing/).
