## Requirements

- Node.js 24 or later, from [nodejs.org](https://nodejs.org). The repo `.nvmrc` pins Node 24, which is what CI tests against.

## Install

A **lexicon** is the plugin that generates output for one platform, such as AWS or Kubernetes. Install the lexicon for your platform, which also installs the chant CLI:

```bash
npm install --save-dev @intentius/chant-lexicon-aws
```

See the [AWS lexicon reference](/chant/lexicons/aws/) for intrinsic functions, composites, and examples.

## Verify the Installation

Check the install:

```bash
chant --version
```

Next, follow the [Quick Start](/chant/getting-started/quick-start/).
