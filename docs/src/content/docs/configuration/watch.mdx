`chant build` and `chant lint` take `--watch`, which re-runs the command when a source file changes.

## Usage

```bash
chant build --watch
chant lint --watch
```

## How It Works

1. chant watches for file create, modify and delete events.
2. It batches changes within a short debounce window.
3. Each batch triggers a full rebuild or re-lint.

## Watched and Ignored Paths

Watch mode monitors all `.ts` files, with these exclusions:

| Ignored Pattern | Reason |
|---|---|
| `node_modules/` | Dependencies don't change during development |
| `.chant/` | Generated types and metadata |
| Hidden directories (`.*/`) | `.git/`, editor configs, tool caches |
| `*.test.ts`, `*.spec.ts` | Test files |
| Non-`.ts` files | Only `.ts` files are watched |

## Tips

- On a large project, debouncing batches rapid saves into one re-run.
- Run watch mode in one terminal pane and your editor in another.
