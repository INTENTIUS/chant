```typescript
// ship.op.ts
import { Op, phase, gate, shell } from "@intentius/chant/op";

export default Op({
  name: "ship",
  overview: "Migrate, wait for a person, then switch traffic",
  phases: [
    phase("Migrate", [shell("./bin/migrate")]),
    phase("Approve", [gate("approve-switch", { timeout: "72h" })]),
    phase("Switch", [shell("./bin/switch")]),
  ],
  onFailure: [phase("Undo", [shell("./bin/undo")])],
});
```

```sh
chant run ship                                # stops at the gate, exits 3
chant approve ship approve-switch --actor alex
chant run ship                                # walks through the gate
```

The first run records that it is waiting and ends. The second run starts again at the first phase, so `Migrate` runs twice unless it is safe to repeat. A gate with `resume: true` picks up where the run stopped. [Resuming at the approved gate](/chant/guide/ops/#resuming-at-the-approved-gate).

`onFailure` phases run when a step fails. A run that stops at a gate has not failed, so they do not run. [Compensation on failure](/chant/guide/ops/#compensation-on-failure).

To tie a gate to one plan, give it `plan:`. A fresh plan with another digest then stops the run again. [A gate approves a plan](/chant/guide/ops/#a-gate-approves-a-plan-not-the-next-run).

[Ops](/chant/guide/ops/) has the step builders.
