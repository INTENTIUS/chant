```sh
chant lifecycle diff prod --live
```

| Finding | Means | Act |
|---|---|---|
| `MISSING` | Declared, gone from the cloud | Re-apply, or update source if the deletion was meant |
| `ORPHAN` | In the cloud, not declared | Adopt it with `chant import --from prod --name <orphan>`, or delete it |
| `DRIFTED` | Changed since the last snapshot | Re-apply, or update source |
| `PROPERTY DRIFT` | A declared field differs from live | Edit the value the report names, or re-apply |
| `UNCLAIMED` | A live value on a field chant never set | Nothing. It never counts as drift |
| `UNOBSERVED` | chant could not read it | Fix the reason shown. Status is unknown |

## Accept a deviation

```sh
chant lifecycle diff prod --live --update-baseline
```

This records the property deviations in `.chant/observation-baseline/prod.json`. Commit the file. A later change away from the accepted value is drift again.

## Check on a schedule

```typescript
// prod-watch.op.ts
import { WatchOp } from "@intentius/chant/op";

const { op } = WatchOp({ name: "prod-watch", env: "prod", schedule: "*/15 * * * *", failOn: "drift" });
export default op;
```

With `failOn: "drift"` the run exits 2 when it finds drift. chant reports and leaves the fix to you. To have it propose one, `ReconcileOp` opens a change that regenerates the source, and an [agent can follow a drift check](/chant/ci/agents/). [Reconcile](/chant/guide/reconciling-lifecycle/), [what to do when drift fires](/chant/guide/watching-lifecycle/#what-to-do-when-drift-fires), [`lifecycle diff`](/chant/cli/lifecycle/#lifecycle-diff-env).
