## The lexicons

Each lexicon is a plugin for one platform: its types, its lint rules and its output format. Install one and `chant init` scaffolds a project for it. [Lexicons](/chant/lexicons/overview/) covers how they work, and [Extend chant](/chant/lexicon-authoring/overview/) covers writing your own.

<Landing part="lexicons" />

## The lifecycle you choose

The build is deterministic and keeps no authoritative state file. What happens after it is up to you, per environment: observe drift, reconcile the source from the live system, or apply the source to it. [Lifecycle Models](/chant/concepts/lifecycle-models/) compares the three.
