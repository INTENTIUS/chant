# Changelog

This file records changes to what chant prints or writes for a plain project, the level-0 changes listed in [#2525](https://github.com/INTENTIUS/chant/issues/2525). The full list, with the release that warned about each one, is on the [level-0 exceptions](docs/src/content/docs/reference/level-0-exceptions.mdx) page.

## Unreleased

- [#4952](https://github.com/INTENTIUS/chant/issues/4952) chant's CLI handlers (`approve`, `components release`, `lock`, `pr`, `pr env`, `promote`, `run`) and the records `workspace release-train`, `workspace run` approvals, auto-release and the source release and rollback activities write take their actor from `actorFromEnv`, so `USERNAME` counts and a blank `GITHUB_ACTOR` falls through. On a shallow checkout the overdue check no longer dates a pipeline file to the oldest commit: when the commit that added the file is at the shallow boundary, it runs `git fetch --unshallow` once and reads the commit again, and when that fails it counts from the boundary and says so in the log. `ciToolInstallLine` and `ciToolFetchScript` take `download: "node"`, which downloads with node's `fetch` and unpacks a zip with node, keeping executable bits, for an image with no curl or unzip. `CI_TOOL_SHA256` records just 1.36.0 and act 0.2.89, and both are now checked against their releases' checksums files (act's `checksums.txt`, just's `SHA256SUMS` from 1.37.0 or its per-file `.sha256sum` in 1.35.0 and 1.36.0). squawk gets no sums: its releases publish no checksums file. terragucci can replace the body of `awsCliScript` and `AWS_CLI` with `ciToolInstallLine("aws-cli", "2.37.9", { download: "node", onPath: true })`, and its curl installs of just and act in `workflows/shared.ts` with `ciToolInstallLine`. Floor: `CI_TOOL_NODE_DOWNLOAD_FLOOR`.

Warning release for four listed level-0 changes. Nothing chant prints on stdout or writes changes in this release; each warning goes to stderr, and the change it warns about can land from the next release.
