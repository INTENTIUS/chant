## 0.125.0 (spec v1.36.2 to v1.37.2)

Upgraded on 2026-11-24.

### Removed

These names are gone from the lexicon and nothing replaces them. Code that imports one no longer builds until the import is taken out.

| Name | Resource type |
|---|---|
| `NodeAllocatableResourceMapping` | `io.k8s.api.resource.v1.NodeAllocatableResourceMapping` |
