The fly lexicon ships 6 top-level resources. Each maps to a Machines API create body; the reference link has the API fields.

| Resource | Type | Service | Machines API |
|----------|------|---------|--------------|
| `App` | `Fly::Machines::App` | Apps | [reference](https://docs.machines.dev/#tag/apps) |
| `Machine` | `Fly::Machines::Machine` | Machines | [reference](https://docs.machines.dev/#tag/machines) |
| `Volume` | `Fly::Machines::Volume` | Storage | [reference](https://docs.machines.dev/#tag/volumes) |
| `IPAddress` | `Fly::Machines::IPAddress` | Networking | [reference](https://fly.io/docs/networking/services/) |
| `Certificate` | `Fly::Machines::Certificate` | Networking | [reference](https://fly.io/docs/networking/custom-domains-with-fly/) |
| `Secret` | `Fly::Machines::Secret` | Secrets | [reference](https://docs.machines.dev/#tag/secrets) |

Property types such as `MachineConfig`, `MachineGuest`, `MachineService`, `MachinePort`, and `MachineMount` are written inline on a resource and documented with it.
