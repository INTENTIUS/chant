## SYS001: a backend key is never a literal

Severity: error. A lint rule over source.

It fires on a `key` property whose value is a string or template literal, inside the `systemone` config namespace or inside a `backends` object, such as a `decide` step's own. A key is `{ env: "VARIABLE" }` or a brokered capability.

```ts
// SYS001
systemone: { backends: { systemone: { url: "https://api.typesafe.ai", key: "sk-..." } } }

// fine
systemone: { backends: { systemone: { url: "https://api.typesafe.ai", key: { env: "TYPESAFE_API_KEY" } } } }
```

## SYS010: a key sent over plain HTTP

Severity: error. A post-synth check over the built entities.

It fires when a backend with a key has an `http://` URL whose host is not loopback, whether the backend is in `systemone.backends` or in a `decide` step's `backends`. The bearer key would cross the network in clear text. A loopback address (127.0.0.1, `::1`, `localhost`) is exempt, since that is where a local server or a broker that is the endpoint listens.
