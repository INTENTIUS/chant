The systemone lexicon writes no output. It declares no resources: a decision point is workspace data in a points file, and its answers are records the `decide` activity writes when an Op runs.

`chant build` still carries the lexicon's part of the build. Each backend in `systemone.backends` joins it as a `Systemone::Backend` entity, and each `decide` step is part of its Op. Core's OPS012 checks the step's arguments against the activity's contract, and SYS010 reads both the backends and the steps. The serializer returns an empty document for them.
