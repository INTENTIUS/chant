## Lint Rules

## Post-Synth Checks

Post-synth checks validate the serialized output after the build pipeline completes.

| ID | Description |
|----|-------------|

| `OTEL102` | A pipeline has no receivers or no exporters |
| `OTEL103` | A declared component is never used |
| `OTEL104` | service.extensions enables an extension that is not declared |
| `OTEL105` | memory_limiter is not the first processor in a pipeline |

| `OTEL109` | A custom component has no schema pin |
