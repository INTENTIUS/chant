The Docker lexicon ships two AI skills that teach coding agents Docker Compose and Dockerfile patterns.

## Installation

Skills are installed automatically when you scaffold a project:

```bash
chant init --lexicon docker my-project
```

To refresh skills after a lexicon update:

```bash
chant update
```

## Skill: chant-docker

Core Docker lexicon usage:

- Resource types: Service, Volume, Network, Config, Secret, Dockerfile
- Build: `chant build src --lexicon docker -o docker-compose.yml`
- Lint: `chant lint src/` and post-synth checks
- Variable interpolation: `env()` with required and default values
- Default labels: `defaultLabels()` scope and merge

## Skill: chant-docker-patterns

Common patterns and composition:

- Database services with health checks and named volumes
- Redis cache, Nginx reverse proxy
- Multi-stage Dockerfiles
- Secret management with `env()` and Docker secrets
- Service networking with named networks

## MCP integration

AI agents can call these MCP tools:

| Tool | Description |
|------|-------------|
| `build` | Build the chant project |
| `lint` | Run lint rules |
| `explain` | Summarize project resources |
| `scaffold` | Generate starter files |
| `search` | Search available resource types |
| `diff` | Show changes between builds |

## LSP integration

Via `chant serve lsp`:

- Completions: type `new ` for Docker resource completions
- Hover: hover over a type name for its Compose/Dockerfile serialization
