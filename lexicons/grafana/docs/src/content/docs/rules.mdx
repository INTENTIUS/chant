The Grafana lexicon provides **9** rules: 2 lint rules and 7 post-synth checks.

## Lint Rules

| ID | Severity | Category | Description |
|----|----------|----------|-------------|
| `GRAF001` | error | correctness | a uid Grafana rejects, or a variable name queries cannot reference. |
| `GRAF002` | error | security | a datasource secret written as a literal. |

## Post-Synth Checks

Post-synth checks validate the serialized output after the build pipeline completes.

| ID | Description |
|----|-------------|
| `GRAF101` | A panel, query or variable uses a datasource no Datasource in the build declares |
| `GRAF102` | A query is sent to a datasource of another plugin type |
| `GRAF103` | A query, title, datasource or repeat uses a variable the dashboard does not declare |
| `GRAF104` | Two dashboards, datasources, panels, variables or queries share an id |
| `GRAF105` | A panel does not fit the 24-column grid, or overlaps another panel |
| `GRAF106` | A dashboard or datasource uid Grafana rejects, or a dashboard with no title |
| `GRAF107` | A dashboard does not match the pinned Grafana schema |
